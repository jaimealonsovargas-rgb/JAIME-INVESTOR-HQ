# VS Code, GitHub y flujo de trabajo

## Descargar
En GitHub: **Code → Download ZIP**, descomprimir, **VS Code → Archivo → Abrir carpeta**. Para guardar cambios y sincronizar, es preferible **GitHub Desktop → Clone repository** o terminal:

    git clone https://github.com/jaimealonsovargas-rgb/JAIME-INVESTOR-HQ.git
    cd JAIME-INVESTOR-HQ
    code .

El repositorio es privado: GitHub puede pedir autenticación. No pegar tokens de GitHub en el chat.

## Codex
Instalar extensión oficial, iniciar sesión, elegir modelo/esfuerzo **manualmente** y copiar CODEX_START_HERE.md. Confirmar comandos e instalaciones. No activar permisos totales ni recursos de pago innecesarios.
