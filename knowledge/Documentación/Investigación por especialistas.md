# Investigación por especialistas

El proyecto define 30 roles lógicos. P4 permanece parcial. El ciclo descriptivo A21 produjo trabajo real con tres roles Python. El debate entre alcista, bajista y presidencia sigue pendiente de aceptación semántica.

Los modelos de [[Apple]], [[Microsoft]] y [[Walmart]] pertenecen a la revisión contable. El laboratorio cuantitativo usa un evaluador determinista. Así se puede reconstruir un ensayo aunque la deliberación de P4 siga abierta. [[Vibe-Trading]] y [[Agent Reach]] documentan qué material de terceros se evaluó y qué uso se aceptó.

[[Agentes financieros de Anthropic]] describe funciones de constructor, analista y revisor dentro de los roles existentes. Se conserva como referencia de diseño.
