# Optuna

JAIME probó la versión 4.9.0 en un entorno opcional de CPU. La interfaz `ask/tell` permite que el optimizador sugiera parámetros y que el motor Python de JAIME evalúe cada propuesta. La poda se limita al desarrollo y cada descarte se conserva para auditoría.

El [[Piloto de búsqueda con Optuna]] documenta las medidas de ingeniería. La ampliación a datos de mercado queda condicionada a una comparación a igual presupuesto y a comprobar qué configuraciones perdería la poda.
