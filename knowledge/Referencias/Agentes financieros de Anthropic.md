# Agentes financieros de Anthropic

JAIME estudió el constructor de modelos, el analista de resultados y el revisor de valoración del repositorio `anthropics/financial-services`. La adaptación propuesta distribuye la obtención de datos, la escritura del modelo y su comprobación entre funciones distintas.

El encaje corresponde a [[Investigación por especialistas]]. Una comparación con consenso requiere una fuente autorizada y fechada antes del anuncio. Python conserva el cálculo verificable y cada revisión enlaza sus evidencias. El estudio quedó como diseño, con coste de servicios de 0 EUR.
